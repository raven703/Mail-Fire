# MICE: исправление RU_PASSPORT, 2026-11-20

## Причина
MF300-0065 успешно разобран: тело и HTML-вложение содержат «Паспорт гражданина РФ», «Серия 45 08, номер 103136», дату и код подразделения. Ошибки извлечения нет. Встроенный Presidio regex требовал непосредственную последовательность `паспорт + 10 цифр`, без слов «гражданина РФ», «серия», «номер». Структурные document_templates в processing запускаются только по Reference с document_template; таких эталонов в базе нет. Прямой match_document на полном тексте может распознать этот пример по заголовкам/дате, но в рабочем pipeline не вызывается без зарегистрированного эталона.

## Путь данных
parse_mail извлекает тело; sandbox/parser_service вызывает extraction.extract для каждого вложения. DOCX включает текст таблиц, XLSX — строки ячеек, HTML — видимый текст. processing.analyze добавляет извлечённый текст к телу и вызывает pii(text). Структурные шаблоны отдельно применяются к каждому вложению при наличии зарегистрированного Reference. Настройки и политики отбирают готовые findings при evaluate, не создают паспортную находку сами.

## Изменения
Общий passport_spans используется встроенным pii и document_templates. Поддерживаются серии 4 или 2+2 цифры, шесть цифр номера, слова «серия», «номер», знак №, разделители и табличные переносы. Обязателен локальный контекст слова «паспорт»; случайные десятизначные числа без него не распознаются. Пустые абзацы отделяют несвязанный контекст. Исключены «паспорт проекта/изделия/оборудования» и нулевые серия/номер. Это форматная эвристика, не проверка по реестру. Старые структурные признаки бланка сохранены. Эталоны не сохраняют персональные значения в evidence.
