## OCR / PDF / MIME

- PDF: 4/4 открываются, текст извлечён с точным совпадением аннотированной строки.
- PNG OCR: 6/6 обработаны, но точная строка (без учёта пробелов/регистра) совпала только у 1/6 (16.67%). PaddleOCR ru искажает латиницу/цифры; ANALYZED не означает корректный OCR.
- Вложения часто повторяют сведения тела письма: успешный DLP не доказывает успешность OCR. Необходимы независимые attachment-only положительные/отрицательные примеры.
- Все 226 вложений имеют ANALYZED; сравнение с полным эталонным текстом доступно только для 10 новых. Статусы старых DOCX/XLSX не подтверждают полную текстовую точность.
- Engine-error сообщений: 0; подробности в engine-errors.json.
