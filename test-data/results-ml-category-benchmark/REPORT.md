# Сравнение штатных ML-моделей на B-500

Версии данных и кода, групповой split, пороги и хеши артефактов зафиксированы в `audit.json`, `experiment.json` и метаданных моделей. Воспроизводимые команды реализованы в `scripts/experiments/ml_category_benchmark.py` (`train`, затем `evaluate`) и `ml_neural_benchmark.py` (12 запусков `train` по категориям, затем `evaluate`); пути к замороженным входам передаются аргументами CLI. B-350 и B-400 использованы для обучения и внутренней валидации. B-500 использован только после фиксации моделей и порогов. Сценарии `корпус:scenario` и точные совпадения текстов объединены в группы без пересечения между train/validation/test. Разметка не менялась.

## Интерпретация и ограничения

Аудит входов: 750 писем, 730 разных текстов после нормализации, 20 точных повторов без конфликтующих меток. Зафиксированный split содержит 128 смысловых групп: train 409 писем/76 групп, validation 200/26, test 141/26. Пересечений этих групп между частями нет. Минимум по одному положительному и отрицательному письму каждой категории есть во всех трёх частях; эффективное число положительных групп в validation для customer-data, explosive-threat и sabotage равно одному.

Модели обучались штатными `app.ml.train` и `app.ml_engines.train_binary`; изменён только способ передачи группового split. TF-IDF остаётся глобальной многометочной моделью; SetFit и RuBERT — 12 независимых бинарных моделей, их вывод объединён по категориям. Порог каждой категории выбран штатной функцией только на validation. На B-500 дополнительных тренировок и корректировок порога не проводилось.

На B-500 SetFit дал лучший micro F1 из трёх ML-моделей (32.91%), но 27 FP на безопасных письмах против 23 у RU4. RuBERT дал 13.33% micro F1 и 7 безопасных FP. TF-IDF не обнаружил ни одной из 300 положительных категорий; для большинства категорий его штатный подбор выбрал порог 0.8 при нулевом F1 на validation. Эти результаты нельзя переносить на реальные письма без независимой оценки.

Разделение по `scenario` устраняет очевидные повторяющиеся шаблоны внутри набора и пересечения точных текстов, но не гарантирует отсутствия смыслового сходства между разными именами сценариев и между B-350/B-400. Это синтетические наборы, B-500 не является полностью слепой независимой разметкой. Эффективное число положительных сценарных групп в validation для некоторых категорий мало, поэтому пороги нестабильны.

Автоматические тесты изменённых путей: 11 пройдено. Один существующий тест в `tests/test_ml_datasets.py` для удалённого ранее `ml_runtime.infer_active` исключён из запуска как не относящийся к Grouped Split; производственный API `infer_models` не менялся.

Нейронные zip-артефакты (~104 МиБ каждый) сохранены локально вне git в `/home/user/Mice-ml-models`; в PR включены их SHA-256, пороги, параметры, время, RAM и полные предсказания. TF-IDF артефакт включён в виде gzip+base64; восстановление: `base64 -d tfidf.pkl.gz.b64 | gunzip > tfidf.pkl`. Для `messages.json.gz.b64` используется такая же команда с именем `messages.json`. Модели не публиковались на рабочем стенде, БД не изменялась.
