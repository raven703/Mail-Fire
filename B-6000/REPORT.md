# Отчёт о corpora B-6000

## Сводка

Создан синтетический корпус из **6000 русскоязычных деловых писем** для обучения моделей классификации корпоративной DLP-системы MICE. Корпус поддерживает многометочную классификацию (multi-label) по двум целевым категориям.

## Файлы корпуса

| Файл | Описание |
|------|----------|
| `dataset.jsonl` | Основной корпус в формате JSONL (6000 писем) |
| `dataset.csv` | То же содержимое в формате CSV |
| `scenarios.jsonl` | Каталог scènes (1660 уникальных сценарных групп) |
| `validate_dataset.py` | Скрипт валидации корпуса |
| `validation_report.json` | Отчёт о валидации |
| `duplicate_report.json` | Отчёт о близких дубликатах |
| `annotation_guidelines.md` | Руководство по разметке |
| `REPORT.md` | Данный отчёт |

## Языковое разнообразие

Корпус включает:
- Официальную и неформальную переписку
- Короткие и длинные аналитические письма
- Ответы, пересылки, протоколы совещаний
- Внутренние уведомления, текстовые таблицы
- Профессиональный жаргон и аббревиатуры
- Опечатки, пропущенные знаки препинания
- Смешение русского и английского языков
- Транслитерацию и обфускацию ключевых слов
- Косвенные формулировки и отрицания

## Ограничения корпуса

1. Письма синтетические, не содержат реальных персональных данных.
2. Небольшая доля очень длинных писем (<1% вместо целевых 10%).
3. Один близкий дубликат выявлен автоматически.
4. Генерация основана на параметризованных сценариях, а не на纯 LLM-генерации каждого письма.

## Рекомендации по обучению

- Использовать Grouped Split по полю `group_id` для разделения на train/validation/test.
- Поля `labels`, `label_reason`, `scenario`, `difficulty`, `features`, `group_id` — только метаданные, не подавать в модель.
- Модель должна обучаться только на `subject` и `body`.
- Рекомендуется обратить внимание на hard negatives (1500 писем) при настройке порога классификации.
