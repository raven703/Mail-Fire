# Руководство по разметке корпуса B-6000

## Обзор

Корпус B-6000 содержит 6000 синтетических русскоязычных деловых писем для обучения моделей классификации корпоративной DLP-системы MICE. Разметка многометочная (multi-label): одно письмо может относиться к нескольким категориям одновременно.

## Целевые категории

### pack-ru2-financial-plans — Непубличные финансовые планы

Письма, раскрывающие внутренние финансовые планы, прогнозы, бюджеты и другие неопublikованные финансовые показатели компании.

**Примеры:**
- Неопубликованные бюджеты подразделений
- Планируемые доходы и расходы
- Прогнозы выручки и прибыли
- Финансовые модели и инвестиционные планы
- Планы сокращения расходов
- CAPEX, OPEX, БДР, БДДС
- Предварительные финансовые результаты до публикации

### pack-ru2-pricing — Специальные цены и коммерческие условия

Письма, раскрывающие непубличные цены, скидки, тарифы и коммерческие условия.

**Примеры:**
- Индивидуальные скидки
- Закрытые прайс-листы
- Дилерские и закупочные цены
- Индивидуальные тарифы
- Ретробонусы
- Минимально допустимые цены продажи
- Непубличные условия тендеров

## Разметка安全 (пустые метки `[]`)

Письма без конфиденциальной финансовой или коммерческой информации. Включают:
- Обычную рабочую переписку (отпуск, командировки, встречи)
- Техническую поддержку
- Обучение сотрудников
- Публичные прайс-листы и скидки
- Опубликованную финансовую отчётность
- Отказы в раскрытии информации (без цитирования конфиденциальных данных)

## Правила разметки

1. **Метки определяются смыслом, а не ключевыми словами.** Отсутствие слов «бюджет», «скидка», «конфиденциально» не делает письмо безопасным.
2. **Многометочность.** Письмо может иметь обе метки одновременно.
3. **Hard negatives.** Письма с лексикой финансов/цен, но не раскрывающие защищаемую информацию, помечаются как безопасные (`[]`).
4. **Утечка через цитирование.** Письмо, отказывающее в раскрытии но цитирующее конфиденциальное приложение, является положительным примером.
5. **Публичное ≠ секретное.** Упоминание публичных цен, тарифов или скидок не делает письмо конфиденциальным.

## Поля метаданных

| Поле | Описание |
|------|----------|
| `id` | Уникальный идентификатор письма (формат B6000-XXXXXX) |
| `group_id` | Идентификатор сценарной группы (для Grouped Split) |
| `subject` | Тема письма |
| `body` | Текст письма |
| `labels` | Список меток категории |
| `industry` | Отрасль компании |
| `scenario` | Название сценарного сюжета |
| `difficulty` | Трудность классификации (easy/medium/hard) |
| `features` | Список языковых признаков письма |
| `label_reason` | Обоснование разметки |

Метаданные не должны использоваться в качестве входных данных для обучения модели. Модель получает только `subject` и `body`.
