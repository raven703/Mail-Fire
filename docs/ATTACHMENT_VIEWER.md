# Просмотр вложений

В карточке письма доступны оригинал, сохранённый текст и результаты DLP.
Просмотр требует разрешения `originals`; открытие и страницы записываются в аудит.
Документы не передаются внешним сервисам и не скачиваются автоматически.

PDF и изображения (включая TIFF) растеризуются в существующем изолированном
parser-сервисе. Это намеренная альтернатива PDF.js: браузер получает только PNG,
не исполняет JavaScript PDF и не открывает ссылки. Доступны страницы и масштаб.
Office-файлы конвертируются в PDF отдельным LibreOffice-контейнером без БД,
секретов, опубликованных портов и внешней сети. Макросы отключены, профиль
одноразовый; установлены лимиты времени, памяти и размера. Конвертация Office
при смене страницы выполняется повторно; постоянный кэш производных не создаётся.

TXT/CSV/JSON/XML показываются как экранированный сохранённый текст.
EML/MSG имеют структурированные заголовки и пассивное текстовое тело.
HTML/SVG не исполняются и не отображаются как активные документы.
Лимит оригинала для просмотра — 20 МБ, страницы — 16 млн пикселей.

OCR при открытии не запускается: вкладка использует `Attachment.text`.
При отсутствии текста требуется отдельная повторная обработка письма.
Старые результаты не содержат координат OCR. Подсветка в PDF ищет точные
текстовые фрагменты сохранённых DLP-результатов; для сканов без текстового
слоя подсветка недоступна. Привязка общих результатов DLP к вложению по фрагменту
может быть неоднозначной при одинаковом тексте в нескольких вложениях.
